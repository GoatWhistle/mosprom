# Presentation rules

The defense deck is plain Markdown: `slides/slides.md`, one `**Слайд N. …**` block per slide,
separated by `---`. Screenshots live in `slides/img/`. There is no build step and no deck engine.

- Slide text is in Russian (the defense language); this file and other agent instructions are English.
- Every figure on a slide comes from a run recorded in `../docs/analytics.md`, `../README.md` or `../work/jury-run-bugs.md`.
  A figure from a third-party source says so; an unmeasured figure is not claimed.
- Screenshots are real chat exports from the stand, copied from the run results, never mock-ups.
- Repo-wide rules in [../AGENTS.md](../AGENTS.md) apply.
