# Исходные материалы

Оригиналы от организаторов — ТЗ, приложения, правила, слайды мастер-классов, записи ответов — лежат
здесь как есть, без переименования содержимого. Каждый файл записан в таблицу с контрольной суммой,
чтобы ссылка «с. N» всегда указывала на ту же версию документа.

| Файл | Что это | Откуда и когда получен | Страниц | SHA-256 |
|---|---|---|---|---|
| `{{файл}}.pdf` | {{ТЗ, приложение, регламент}} | {{Канал, ГГГГ-ММ-ДД}} | {{N}} | `{{хеш}}` |

Контрольная сумма:

```bash
sha256sum brief/sources/*
```

В PowerShell — `Get-FileHash brief/sources/* -Algorithm SHA256`.

Если организаторы присылают новую версию файла, старая остаётся рядом, в таблице появляется новая
строка, а [TASK.md](../TASK.md) сверяется с новой версией; расхождения записываются в
[open-questions.md](../../context/open-questions.md).
