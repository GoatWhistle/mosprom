# Brim 0.6.1 для STE Slicer

Brim добавляет чат, который читает задачу и файлы пользователя, анализирует состояние сцены,
выбирает материал и настройки, применяет изменения и запускает нарезку. Результат — проект 3MF,
G-code и история принятых решений. Чат доступен в правой панели STE и в системном браузере.

## Требования

Проверенная поставка: STE Slicer 7.10.12 на Windows 10. Цель совместимости плагина — Python 3.5,
PyQt5 и API плагинов 5. Основной профиль задания — Stereotech Hybrid 530 V5.2.4.
Для 5D требуется активированный движок и корректный запуск STE из его папки установки.

Нужен OpenAI-совместимый Chat Completions API с tool calling; для фото — поддержка `image_url`.
Дополнительный backend или база данных для прямого подключения не требуются.
Без доступной LLM плагин сообщает об ошибке; офлайн-ответов по сценарию нет.

## Установка

1. Закройте STE Slicer. При обновлении сохраните копию прежней папки Brim.
2. Скопируйте папку `Brim` рядом с этим README в пользовательскую папку `plugins` слайсера:
   обычно `%APPDATA%\steslicer\7.x\plugins`.
3. Итоговый путь должен выглядеть как `plugins\Brim\plugin.json`, без лишней вложенности.
4. Перезапустите STE. В меню появится Brim.

Папку конфигурации можно заранее открыть через «Справка → Показать папку конфигурации».
Если вы работаете из полного репозитория, сначала выполните из его корня
`python3 plugin/build.py`; установочный архив появится в `plugin/dist/Brim-0.6.1.zip`.

## Настройка URL и ключа

Откройте «Brim → Настройки» или шестерёнку чата:

| Поле | Что указать |
|---|---|
| URL LLM | Базовый URL провайдера, например `https://host/v1`; не добавляйте `/chat/completions` |
| Модель | Точное имя модели у провайдера |
| Ключ доступа | Выданный ключ; пустое поле при сохранении оставляет прежний ключ |
| Язык / тема | RU или EN; светлая или тёмная |
| MCP-серверы | Необязательно: имя, HTTP URL и один заголовок авторизации |

«Проверить соединение» запрашивает `/models` и каталоги MCP. Успех этой кнопки ещё не проверяет
полноценный вызов модели с изображением и инструментами. Встроенный MCP Brim включён всегда.

Ключ хранится в Preferences STE Slicer. Файлы чатов и ключ не шифруются плагином.
LLM получает историю, прочитанные документы, изображения и состояние сцены; используйте
провайдера, которому разрешено передавать эти данные.

## Первый проект

1. Откройте «Brim → Открыть чат», создайте новый чат.
2. Прикрепите STL/OBJ/3MF, ТЗ и изображения. Напишите, для чего нужна деталь, её нагрузки и ограничения.
3. Ответьте на вопросы. Кнопки вариантов вставляют текст в поле; отправьте выбранный ответ.
4. В режиме «С подтверждением» примените или отклоните предложенные изменения. Комментарий
   в поле ввода при отклонении возвращается агенту.
5. После нарезки просмотрите результат и файлы. Оценки времени и материала вычислены слайсером.

В «Авто» обычные изменения выполняются сразу, но числовые значения за границами слайсера и резкие
изменения могут потребовать подтверждения. «Остановить» не откатывает выполненные операции.

Каждый чат хранит свой проект. При переключении текущая сцена сохраняется, целевая открывается;
при запросе STE завершите диалог открытия 3MF. При сбое используйте «Восстановить проект».
Новый чат сбрасывает объекты и overrides, но может сохранить материалы экструдеров — проверьте их.
Несохранённые черновики и неотправленные вложения не переживают перезапуск.

## Файлы и специализации

К сообщению можно прикрепить до восьми файлов. Модели STL/OBJ/3MF и JPG/JPEG/PNG — до 100 MiB
на файл; документы DOCX/XLSX/CSV/TSV/TXT/MD/JSON/PDF — до 20 MiB. PDF должен иметь текстовый слой;
OCR и шифрование не поддерживаются. XLSX читается без пересчёта формул.

Скилл можно закрепить вручную или оставить Авто:

- «Новичок»: объяснения, пробные детали и калибровка.
- «Инженер»: требования ТЗ, геометрия и расчёты с допущениями.
- «Материал»: кандидаты из каталога слайсера по условиям эксплуатации.
- «Дефекты»: причины и настройки по описанию или фото отпечатка.

Общая калибровочная фигурка имеет зоны для первого слоя, нависаний, моста, нитей, отверстий,
тонкой стенки, мелких деталей и верхней поверхности. Журнал связывает попытки, фото и изменения.
Генерация/нарезка проверены; улучшение физических отпечатков по реальным фото не подтверждено.

## Браузер и экспорт

«Brim → Открыть в браузере» запускает тот же чат на `127.0.0.1` с локальным токеном.
После перезапуска STE откройте страницу из меню заново: старые порт и токен недействительны.
Из карточки результата можно скачать G-code и 3MF.

Полный экспорт делается кнопкой в шапке панели слайсера: выберите папку `results`, плагин создаст
подпапку модели с `project.3mf`, `result.gcode`, `chat.md` и `chat_01.png` и далее.
Во время снимков не прокручивайте панель. Без успешного слайсинга экспорт не содержит файлов печати.
Повторный экспорт заменяет прежние PNG в целевой подпапке.

Данные находятся в `<каталог данных STE>/brim/chats/<id>/`. Для резервной копии закройте STE
и скопируйте весь каталог `brim/`. Автоматической синхронизации истории между машинами нет.

## Типовые проблемы

| Симптом | Действие |
|---|---|
| Нет меню | Проверить путь к plugin.json, перезапустить, прочитать журнал STE |
| LLM недоступна | Проверить URL, ключ и сеть именно с машины STE; localhost в VM означает VM |
| 5D не видит OpenSCAD | Запускать STE с рабочей папкой его установки |
| 5D требует активацию | Активировать поставку по инструкции организаторов |
| После 5D classic стоит на 0 % | Сохранить проект, остановить ход и перезапустить STE; открытая ошибка движка |
| Не видно подтверждения | Нажать «Новые сообщения» и найти карточку внизу |
| PDF не прочитан | Передать текстовый PDF, DOCX или изображения |
| Зависло переключение | Завершить диалог STE или использовать «Восстановить проект» |

Двухэкструдерная нарезка нестабильна. В текущем сценарии рекомендуется один экструдер.
Длинные варианты ответа могут обрезаться, названия похожих чатов — совпадать. Проверяйте
действия по ленте инструментов: LLM может ошибиться в описании состояния.

## Локальный MCP и необязательный прокси

Внешний клиент может читать `<каталог данных STE>/brim/mcp.json` и обращаться к его `url` с
`Authorization: Bearer <token>`. Доступны JSON-RPC `initialize`, `ping`, `tools/list`, `tools/call`.
Токен даёт управление текущей сценой без карточек подтверждения; не передавайте его другим людям.

Для Claude в полном репозитории есть backend. Он принимает `/v1/chat/completions`, требует
OAuth-токен из `claude setup-token` и всегда выбирает `opus`. На машине backend URL обычно
`http://127.0.0.1:8000/v1`; для VM нужен сетевой доступ к хосту. Прямое подключение к LLM
организаторов обходится без этого сервиса.

## Песочница интерфейса

Окно чата плагина и чат в браузере без слайсера и без модели, на настоящем `ChatPresenter`:

```
uv run --no-project --python 3.12 --with PyQt5==5.15.11 plugin/tools/playground.py
```

Ответы агента скриптовые. Команды в поле ввода: `вопрос`, `подтверждение`, `результат`, `ошибка`,
`markdown`, `все`; любой другой текст даёт обычный ответ со списком команд. Тема и язык меняются в
настройках, как в слайсере. В консоль печатается адрес браузерного чата на тех же данных.
Интерфейс рисуется программно (`QT_QUICK_BACKEND=software`); `BRIM_SOFTWARE=0` включает OpenGL.
Для автоматических снимков: `BRIM_SHOT=<png>`, `BRIM_SHOT_MS`, `BRIM_SCRIPT="300=send:все;4000=settings:en,light"`,
`BRIM_HIDDEN=1` прячет окно и не забирает фокус.
