# Картинки README

Баннер, кнопки, бейджи и знак в подвале README. Каждая картинка — в двух вариантах, `*.light.png` и
`*.dark.png`; README выбирает вариант по теме GitHub через `<picture>`.

Картинки — готовые PNG на токенах, шрифтах и знаке продукта. Генератор удалён вместе с движком
презентаций, поэтому новая кнопка или бейдж делается отдельно в тех же цветах
([визуальная система](../visual-system.md)).
