# Картинки README

Баннер, кнопки, бейджи и знак в подвале README. Каждая картинка — в двух вариантах, `*.light-<хэш>.png` и
`*.dark-<хэш>.png`: хэш содержимого в имени не даёт браузеру показать старую версию из кэша; README выбирает вариант по теме GitHub через `<picture>`.

Картинки — готовые PNG на токенах, шрифтах и знаке продукта. Новая кнопка или бейдж делается
в тех же цветах ([визуальная система](../visual-system.md)).
