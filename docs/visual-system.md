# Визуальная система Brim

> Brim — это кайма из линий вокруг детали на первом слое: она удерживает деталь на столе, пока идёт
> печать. Продукт делает то же для слайсера: подбирает параметры так, чтобы печать удалась с первого
> раза. Визуально это тёмная мастерская с одним тёплым источником света. Текст и данные стоят у краёв
> экрана, в центре — модель, а единственный яркий цвет — раскалённый пластик.

**Живой брендбук:** [`brand/index.html`](brand/index.html) показывает все варианты знака, палитру,
шрифты и анимации. **Исходники:** [`brand/`](brand/README.md). **Значения для презентации:** `presentation/src/core/css/tokens.css`.
Веб-фронтенд удалён; описания его экранов и анимаций ниже остаются дизайн-ориентирами,
а не реализованным интерфейсом плагина.

Стиль-источник — Refero «Max Yinger» (yinger.dev): тёмный холст, тёплый белый текст, моноширинная
телеметрия, плотная сетка с шагом 4 px, один 3D-объект в центре.

## 1. Логотип

### Состав

| Часть | Что это | Файл |
|---|---|---|
| Знак | Деталь и три кольца каймы. Внутренний квадрат — деталь, кольца с каждым шагом скругляются сильнее, как круги по воде. Внешнее кольцо — первая линия печати, она акцентного цвета | `symbol-dark.svg`, `symbol-light.svg` |
| Пиксельный знак | Тот же знак, нарисованный по сетке 16×16 для фавикона | `symbol-small.svg` |
| Словесный знак | `brim` строчными: собственная монолинейная геометрия с толщиной штриха 13 из 90 по высоте, скругления повторяют кольца. Шрифтом не набирается | `wordmark-dark.svg`, `wordmark-light.svg` |
| Горизонтальный локап | Знак слева, имя справа | `lockup-dark.svg`, `lockup-light.svg` |
| Вертикальный локап | Знак сверху, имя снизу по центру | `lockup-stacked-dark.svg`, `lockup-stacked-light.svg` |
| Одноцветные | Для гравировки, печати в один цвет, водяных знаков | `symbol-white.svg`, `symbol-black.svg` |
| Анимированный | Деталь появляется, кольца расходятся и гаснут; учитывает `prefers-reduced-motion` | `symbol-animated.svg` |

Имя работает и без знака: в тексте, в чате, в заголовке вкладки пишется `Brim` с заглавной, в логотипе —
`brim` строчными. Знак никогда не встраивается внутрь букв.

### Геометрия локапа

- Высота имени (от верха `b` до базовой линии) — 0,62 высоты знака.
- Расстояние от знака до имени — 0,25 высоты знака.
- Имя центрируется по высоте знака: середина габарита букв совпадает с серединой знака.
- Охранное поле — расстояние между кольцами знака (≈ 6 % его ширины) с каждой стороны; в нём нет
  текста и других знаков.

### Минимальные размеры

| Вариант | Минимум | Меньше этого |
|---|---|---|
| Векторный знак | 24 px | Пиксельный знак `symbol-small.svg` |
| Пиксельный знак | 16 px | — |
| Горизонтальный локап | 96 px по ширине | Только знак |
| Словесный знак | 48 px по ширине | Только знак |

### Цвет логотипа

| Фон | Знак и имя | Внешнее кольцо |
|---|---|---|
| Тёмный (`#12130f`) | `#e4dfda` | `#ff8a3d` |
| Светлый (`#f6f5f2`) | `#12130f` | `#ff8a3d` |
| Фото, цвет бренда, неизвестный фон | Одноцветный белый или чёрный | Тот же цвет |

### Нельзя

- Перекрашивать кольца в разные цвета, кроме внешнего.
- Менять пропорции колец, растягивать, поворачивать, добавлять тень, обводку или свечение.
- Ставить имя под другим углом к знаку или ближе охранного поля.
- Набирать `brim` шрифтом вместо файла словесного знака.
- Ставить знак на пёстрый фон без одноцветного варианта.

## 2. Цвет

Тёмная тема — основная: в ней бренд выглядит так, как задуман. Светлая — чистая бумага без бежевого
оттенка, тот же акцент.

### Палитра

| Токен | Hex | Роль |
|---|---|---|
| `--carbon-950` | `#0b0c09` | Утопленные области в тёмной теме, хром браузера |
| `--carbon-900` | `#12130f` | Фон тёмной темы, текст светлой |
| `--carbon-850` | `#191a15` | Поднятые панели в тёмной теме |
| `--carbon-800` | `#22231d` | Выбранное в тёмной теме |
| `--carbon-700` | `#3c3c38` | Линии и сетка стола |
| `--ash-600` | `#4d4944` | Вторичный текст на светлом |
| `--ash-550` | `#615c56` | Приглушённый текст на светлом |
| `--ash-400` | `#9b968f` | Приглушённый текст на тёмном |
| `--ash-300` | `#b5b0aa` | Вторичный текст на тёмном |
| `--bone-100` | `#e4dfda` | Основной текст тёмной темы, «тёплый белый» |
| `--paper-0` / `-50` / `-100` | `#ffffff` / `#f6f5f2` / `#ecebe7` | Панели, фон и утопленные области светлой темы |
| `--hot-400` | `#ff8a3d` | Раскалённый пластик: главное действие, фокус, внешнее кольцо знака |
| `--hot-300` / `--hot-500` | `#ffa565` / `#f2752a` | Наведение в тёмной и светлой теме |
| `--hot-700` | `#b83f0a` | Акцентный текст и фокус на светлом фоне |
| `--green-*`, `--yellow-*`, `--red-*` | см. токены | Статусы: печатает, требует внимания, ошибка |

### Правила

- Акцент означает одно: главное действие и текущий процесс (печатает, слайсится, выбрано). Это не
  украшение и не цвет заголовков.
- На оранжевой кнопке текст всегда тёмный `#12130f` в обеих темах (контраст 7,9:1).
- Статус всегда передаётся иконкой и словом, цвет только подкрепляет. Жёлтый для «внимания»
  специально отличается от оранжевого акцента.
- Контраст текста ≥ 4,5:1 на каждой поверхности обеих тем проверяет `npm run rules` (правило `contrast`).
- Никаких градиентов, свечения, стекла. Глубину дают кольца знака и 3D-модель, а не тени.

## 3. Типографика

| Роль | Шрифт | Где |
|---|---|---|
| Текст интерфейса и заголовки | Onest (кириллица и латиница) | Всё, что читается: чат, подписи, кнопки |
| Телеметрия и код | JetBrains Mono | `NOZZLE 215°C`, параметры, G-код, пути, идентификаторы |
| Табло | Handjet | Крупные числа: время печати, прогресс, температура — как на экране принтера |
| Логотип | Собственная геометрия | Только файлы `wordmark-*.svg` |

- Шкала: 12 / 13 / 14 / 16 / 20 / 30 / 48 px и табло до 80 px. Других размеров нет.
- Межстрочный интервал плотный: 1,4 для текста, 1,13 для заголовков, 0,78 для табло.
- Контраст создаётся гарнитурой и размером, а не жирностью: обычный 400 и средний 500.
- Подписи-телеметрия: JetBrains Mono 12 px, прописные, трекинг −0,04em.
- Числа в колонках — моноширинные цифры (`--font-numeric`).

## 4. Сетка, формы, плотность

- База 4 px. Шкала отступов: 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- Плотно, как в кабине: между строками группы 4–8 px, внутри панели 16 px, между секциями 48–64 px.
- Вся ширина экрана, без узкой колонки по центру: слева чат, по центру модель, справа параметры.
- Скругления: панели и карточки 0 px, поля ввода 6 px, кнопки, переключатели и метки — «таблетки».
- Панели отделяются линией толщиной 1 px и отступом, а не тенью.

## 5. Визуальные элементы

| Элемент | Как выглядит | Где использовать |
|---|---|---|
| Кольца каймы | 1–3 концентрических скруглённых контура вокруг объекта | Выбранная модель, активный принтер, загрузка, уверенность ассистента (больше колец — увереннее) |
| Сетка стола | Точки с шагом 16 px | Фон 3D-просмотра и превью G-кода |
| Телеметрия | Моноширинные прописные подписи у краёв | Шапка и подвал: температуры, слой, время |
| Пунктир холостого хода | Штрих 16/10 px, бежит по линии | Переходы между шагами, связь чата с принтером |
| Слои | Горизонтальные полосы, растущие снизу вверх | Прогресс печати и слайсинга |
| Комментарии G-кода | `; готово`, `; слой 142/380` | Подписи к ответам ассистента и статусам |

## 6. Движение

Движение подсказывает, что произошло, и всегда повторяет язык печати: слои растут снизу, кольца
расходятся от детали, головка идёт по пунктиру.

| Сцена | Что происходит | Токены |
|---|---|---|
| Загрузка страницы (G28) | Деталь знака проявляется, три кольца расходятся изнутри наружу по очереди | `--motion-brim-part`, `--motion-brim-ring-in`, `--stagger-ring` |
| Ожидание | Кольца знака циклично расходятся и гаснут — это и есть индикатор загрузки | `--motion-brim-ring-loop` |
| Смена темы — «печать слоями» | Восемь полос цвета новой темы ложатся снизу вверх зигзагом, слева и справа по очереди, по переднему краю каждой идёт оранжевая линия сопла. Когда экран закрыт, тема меняется, полосы растворяются | `--dur-layer`, `--stagger-layer`, `--ease-wave`, `--shadow-nozzle-*` |
| Смена языка — «расшифровка» | Заголовки, кнопки и подписи на полсекунды превращаются в символы G-кода и собираются в новый текст слева направо; абзацы мягко проявляются | `--dur-scramble`, `--dur-panel` |
| Нажатие | Кнопка сжимается до 0,97 | `--press-scale` |
| Холостой ход | Пунктир бежит по линии | `--motion-travel` |

Правила:

- Анимируются только `transform` и `opacity`; «расшифровка» меняет только текст коротких строк.
  Никаких снимков страницы и масок во весь экран: полосы темы вместе занимают ровно один экран.
- Где нет Web Animations, смена темы и языка мгновенная; тема применяется, даже если анимация
  прервалась.
- `prefers-reduced-motion`: длительности 1 мс, циклы выключены, знак стоит статично.
- Короткие реакции интерфейса укладываются в 300 мс; длиннее только редкие события: расшифровка
  языка и циклы ожидания (список в `RARE_EVENT_DURATIONS`).

## 7. Голос и шутки

Brim говорит как опытный технолог у принтера: спокойно, с цифрами и единицами, объясняет причину
выбора и не паникует.

| Brim такой | Brim никогда не |
|---|---|
| Точный | Многословный |
| Спокойный | Восторженный |
| Мастеровой | Канцелярский |

- «Слой 0,2 мм: модель высокая, а скорость важнее мелких деталей».
- «Layer 0.2 mm: the model is tall and speed matters more than fine detail».

Шутки для своих, без ущерба смыслу:

- `G28` — при загрузке знак «паркуется», как принтер в начале каждой печати.
- `M600` — команда смены пластика; в интерфейсе ей можно сменить цвет акцента.
- «Сопли» (стрингинг) — тонкие нити между элементами в состоянии ошибки.
- 3DBenchy — кораблик-тест как первая модель в демо и картинка на странице 404.
