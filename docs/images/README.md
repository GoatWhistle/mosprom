# Скриншоты продукта

`hero.png` — настоящий снимок чата Brim на стенде STE Slicer 7.10.12 от 24.10.2026:
расчёт шестерни по Льюису и предупреждение о недостаточном запасе под нагрузку из ТЗ.
Снимок не доказывает физическую прочность детали.
Баннеры в `docs/readme/` — оформление, а не снимки интерфейса.

При добавлении изображения укажите дату, версию Brim, входные данные и наблюдаемый результат
в подписи. Используйте реальный интерфейс, PNG и размер, при котором читается текст; не заменяйте
живой прогон макетом. Уберите ключи и личные данные. Снимки тестовой среды с заглушками отмечайте
отдельно от реального STE.

Файлы называйте по содержанию, например `gear-result.png`. Проверяйте читаемость на ширине
README. Для снимков длинной переписки используйте экспорт панели, а не одну уменьшенную картинку.
