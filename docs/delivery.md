# Подготовка комплекта сдачи

По техническому ТЗ §7 сдаётся один ZIP с исходниками плагина, README и результатами каждой модели.
Срок PDF: 25 октября до 10:00 МСК, защита с 12:00 МСК; личный слот определяется платформой.
Год 2026 принят из контекста мероприятия. Лимит размера архива в доступных материалах не указан.

## Структура

```text
<team_name>.zip
  plugin/
    README.md
    Brim/
      plugin.json
      __init__.py
      ...
  results/
    <model_name>/
      project.3mf
      result.gcode
      chat_01.png
      ...
      chat.md
```

`chat.md` — дополнительный удобный текст; он не заменяет требуемые снимки.
`<team_name>` и `<model_name>` заменяются реальными именами при подготовке комплекта.
Установочный `Brim-0.5.2.zip` содержит только `Brim/` и не является финальным ZIP для жюри.

## Подготовка

1. Соберите плагин командой `python3 plugin/build.py`; проверьте версию в `plugin.json`.
2. Создайте отдельную папку комплекта. В `plugin/` поместите `plugin/README.md` и содержимое
   установочного ZIP, чтобы рядом с README лежала папка `Brim/`.
3. Получите финальные результаты всех семи моделей со стенда. Используйте экспорт текущего чата
   из панели, сохраните исходные имена моделей и исключите старые неудачные варианты из финальных
   папок. Историю неудач сохраняйте отдельно в рабочем журнале.
4. Для каждой модели проверьте комплект по пунктам ниже. Упакуйте `plugin/` и `results/` в один ZIP.
5. Выполните пробную установку из этого комплекта в чистую конфигурацию STE и повторите хотя бы
   один маршрут до результата. Вручную загрузите архив на платформу и сохраните подтверждение.

Сборка и публикация финального комплекта не выполнены самим фактом обновления этой документации.
В текущем checkout результатов стенда нет; их надо перенести перед упаковкой.

## Проверка каждой модели

- `project.3mf` открывается как проект с нужным принтером, режимом, материалом и настройками.
- Геометрия, положение и ориентация соответствуют диалогу; после открытия не подменились материал
  или параметры текущего профиля машины.
- G-code относится к последней успешной нарезке этого проекта; заголовок и используемые экструдеры
  соответствуют настройкам. Для 5D проверяются соответствующие движения и просмотр траекторий.
- В `cylindrical_full` могут быть два заголовка времени: 3D-ядро и 5D-часть. Одно первое значение
  не даёт полного времени.
- Снимки читаемы, отражают настоящую переписку и согласованные решения, не содержат ключей.
- В результате явно указаны невыполненные условия ТЗ. Например, расчёт с запасом меньше единицы
  нельзя описывать как подтверждённую прочность.

Для итогового ZIP выполните `python3 -m zipfile -t <путь-к-архиву>` и запишите SHA-256.
CRC проверяет целостность архива, но не правильность печатных настроек.

В прошлых прогонах G-code Wilo занимал около 201 МБ, фигурки — 298 МБ. Эти размеры относятся
к конкретным экспортам от 24.10.2026. Уточните лимит платформы до загрузки; не уменьшайте детализацию
или не удаляйте требуемые файлы только ради размера без повторной проверки результата.
