# Зависимости

> Компоненты, библиотеки и модели Brim с версиями и лицензиями. Версии — те, что закреплены в
> lock-файлах и образах `docker-compose.yml`. Плагин использует только стандартную библиотеку Python
> и PyQt5 из дистрибутива STE Slicer.

**Читайте, если** вы проверяете лицензионную чистоту или собираете решение в своей среде ·
**Связано:** [архитектура](architecture.md) · [запуск](running.md)

---

## Из чего собран стенд?

| Компонент | Версия | Лицензия | Роль |
|---|---|---|---|
| Python | 3.12 | PSF-2.0 | Бэкенд |
| Python STE Slicer | 3.5, PyQt5 | PSF-2.0, GPL-3.0 | Плагин: только стандартная библиотека |

## Какие библиотеки у бэкенда?

Источник версий — `backend/uv.lock`.

| Библиотека | Версия | Лицензия | Зачем |
|---|---|---|---|
| FastAPI | 0.143.1 | MIT | HTTP API и OpenAPI |
| Pydantic | 2.14.1 | MIT | Схемы запросов и ответов |
| uvicorn | 0.54.0 | BSD-3-Clause | ASGI-сервер |
| claude-agent-sdk | 0.2.173 | MIT; встроенный CLI Claude Code — по условиям Anthropic | Группа `llm`, в образе при `LLM=true`. Ответы `/v1/chat/completions` через Claude по подписке |
| openai-codex | 0.162.1 | Apache-2.0, вместе со встроенным `openai-codex-cli-bin` | Группа `llm`, в образе при `LLM=true`. Вызов моделей Codex для порта `LanguageModel` |
| httpx | 0.28.1 | BSD-3-Clause | Клиент `TestClient` в тестах FastAPI |

## Какие модели и данные используются?

| Модель или набор | Версия, источник | Лицензия | Где используется | Изменялась ли |
|---|---|---|---|---|
| `dashscope/qwen3.8-flash` | LLM организаторов через `https://api.timeweb.ai/v1` | Условия организаторов | Основной LLM плагина | Нет |
| Claude (`sonnet`, `opus`) | Anthropic, по подписке через backend-прокси | Условия Anthropic | Необязательный LLM плагина | Нет |
| Справочники материалов и дефектов | `plugin/Brim/knowledge/*.json`, собраны командой по техническим листам производителей | MIT, как репозиторий | Подбор материала, разбор дефектов | Нет |

## Как обновить таблицы?

```bash
cd backend && uv tree --depth 1
```

Лицензии библиотек бэкенда — `uv run --with pip-licenses pip-licenses --from=mixed` из `backend/`.
