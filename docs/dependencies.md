# Зависимости и поставка

Версии указаны по исходникам и lock-файлам на `23f7329`. Brim не поставляет STE Slicer,
веса LLM или данные авторизации. Основной плагин использует Python и Qt из установки STE.

## Среда плагина

| Компонент | Версия / источник | Роль |
|---|---|---|
| STE Slicer | На стенде 7.10.12, поставка организаторов | Сцена, профили, материалы, 3D/5D-движки, чтение/запись проектов |
| Python | Цель совместимости 3.5 | Код плагина, HTTP, JSON, XML, ZIP, документы |
| PyQt5 / QML | Из поставки STE; журнал стенда указывает Qt 5.10 | Панель, события, главный поток |
| Uranium, steslicer | Из поставки STE, API плагинов 5 | Интеграция с приложением |
| HTML/CSS/JavaScript | Файлы `plugin/Brim/web/`, без npm-сборки | Браузерный чат |

Для `plugin/Brim` нет отдельного pip requirements: зависимости предоставляет STE или стандартная
библиотека. Внешние движки нарезки и OpenSCAD входят в окружение STE; Brim не управляет их версиями
и лицензированием. Для 5D нужна активация поставки.

## Необязательный backend

Источник точных Python-версий — [uv.lock](../backend/uv.lock), диапазонов —
[pyproject.toml](../backend/pyproject.toml).

| Пакет | Версия в lock | Роль | Сведения о лицензии |
|---|---|---|---|
| FastAPI | 0.143.1 | HTTP и OpenAPI | MIT, метаданные установленного пакета |
| Pydantic | 2.14.1 | Проверка HTTP-ошибок и схемы FastAPI | MIT, метаданные пакета |
| uvicorn | 0.54.0 | ASGI-сервер | BSD-3-Clause, метаданные пакета |
| httpx | 0.28.1 | Отправка запросов зеркала и HTTP-тесты | BSD-3-Clause, метаданные пакета |
| claude-agent-sdk | 0.2.173 | Адаптер Claude, группа `llm` | MIT по метаданным пакета; условия встроенного CLI проверяются отдельно |
| pytest | 9.1.1 | Тесты | Инструмент разработки |
| mypy | 2.4.0 | Статическая типизация | Инструмент разработки |
| Ruff | 0.17.0 | Статические проверки | Инструмент разработки |

Backend требует Python ≥3.12. Dockerfile закрепляет `python:3.12.15-slim` и `uv:0.11.33`
с SHA-256 digest; точные digest находятся в [Dockerfile](../backend/Dockerfile).
Сборка ставит зависимости с `uv sync --locked`, группа `llm` включается аргументом `LLM=true`.

## Документация и презентация

Презентация хранится как Markdown в `presentation/slides/slides.md`; npm-сборки и движка нет.
Снимки для слайдов — в `presentation/slides/img/`, готовые PNG оформления README — в `docs/readme/`.
Исходники бренда — в `docs/brand/`. Стили работающих оболочек находятся в
`plugin/Brim/ui/qml/Theme.qml` и `plugin/Brim/web/styles/tokens/`.

## Модели и данные

Модель LLM выбирается в настройках прямого подключения. Для проверки семи деталей использован
Claude через прокси; текущий прокси выбирает `opus`. Для API организаторов отдельно проверялось
имя `dashscope/qwen3.8-flash`. Это имена API, веса моделей в репозиторий не входят,
дообучение в проекте не выполнялось.

Модели STL, документы DOCX и изображения получены от организаторов для кейса. Сам факт выдачи
участникам не задаёт универсальную лицензию на дальнейшее распространение. Условия их использования
и право публикации вне комплекта конкурса должны подтверждаться организаторами.

`knowledge/materials.json` и `knowledge/defects.json` — встроенные справочники проекта.
Свойства семейств полимеров и шаги коррекции служат исходными оценками; библиографическая проверка
каждой записи и паспорта конкретных марок в эту поставку не включены.

Корневой [LICENSE](../LICENSE) задаёт MIT для кода проекта. Он не заменяет условия STE, Qt,
поставляемых движков, внешних сервисов или данных организаторов.

## Обновление

После изменения зависимостей пересоберите lock штатным менеджером, затем обновите эту страницу
и выполните проверки из [инструкции запуска](running.md). Команда `cd backend && uv tree --depth 1`
показывает дерево Python-зависимостей; первая синхронизация может потребовать сеть.
