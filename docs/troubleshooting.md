# Устранение неполадок

Сначала сохраните открытый проект, если интерфейс отвечает. Для сообщения об ошибке нужны
версия STE и Brim, режим печати, материал, действие перед сбоем и строки журналов `*.log` /
`stderr.log` из папки конфигурации. Не публикуйте ключи из Preferences или токен `brim/mcp.json`.

| Симптом | Причина или проверка | Действие |
|---|---|---|
| Нет меню Brim | Неверная вложенность каталогов или ошибка загрузки | Проверьте `plugins/Brim/plugin.json`, перезапустите STE, прочитайте лог |
| Панель не встроилась | Не найдена ожидаемая внутренняя раскладка STE | Используйте отдельное окно из меню или браузер; версия STE может отличаться от проверенной |
| `LLM URL and model are not configured` | Не заполнены обязательные поля | Укажите базовый URL и имя модели |
| `LLM is unreachable` | Адрес недоступен с машины слайсера | Проверьте URL, сеть и туннель; `localhost` в VM не ведёт на хост |
| HTTP 401/403 от LLM | Неверный ключ или нет доступа | Проверьте доступ у провайдера, обновите ключ в Brim |
| HTTP 429 | Ограничение провайдера | Дождитесь восстановления квоты; не запускайте повторные ходы одновременно |
| Backend отвечает 503 | Нет SDK, неверная авторизация, таймаут или некорректный ответ Claude | Проверьте лог, сборку с `LLM=true` и токен; health не проверяет Claude |
| Compose не находит образ | Bake и Compose использовали разные имена | Пересоберите с одинаковыми `COMPOSE_PROJECT_NAME` и `TAG` по инструкции запуска |
| Старая вкладка браузера потеряла связь | После перезапуска STE меняются порт и токен | Снова откройте «Brim → Открыть в браузере» |
| 5D: `No SCAD available` | STE запущен из другой рабочей папки | Запускайте из папки установки STE, где находится поставленный OpenSCAD |
| 5D открывает окно ATSS | Движок не активирован | Выполните активацию по инструкции организаторов и перезапустите STE |
| `cylindrical_full` зависает на детали с осевым отверстием | Нет материала для центрального 3D-ядра | Проверьте `rotation_axis_5d`; обсудите `cylindrical` и диаметр основания с агентом |
| Следующая 3D-нарезка стоит на 0 % после 5D | На стенде наблюдалось завершение процесса CuraEngine | Остановите ход, сохраните проект и перезапустите STE; автоматического исправления нет |
| Открытие чата ждёт диалог STE | Не завершено открытие 3MF | Завершите диалог; при таймауте используйте «Восстановить проект» |
| Материал нового чата неожиданен | Материалы экструдеров не сбрасываются вместе с overrides | Явно задайте материал на нужном экструдере перед нарезкой |
| Не видно нового подтверждения | Лента прокручена выше или сработала известная ошибка прокрутки | Нажмите «Новые сообщения», найдите карточку внизу |
| PDF не читается | Нет текстового слоя, шифрование или неподдерживаемое устройство PDF | Передайте исходный DOCX, текст или отдельные изображения |
| Долго ждём модель | Ответ приходит целиком; у прокси каждый шаг запускает отдельный вызов Claude | Смотрите фазу и таймер; при необходимости остановите ход |
| В экспорте нет 3MF/G-code | В этом чате не завершилась успешная нарезка | Получите успешный результат и повторите экспорт |

## Восстановление рабочего пространства

Не создавайте новый чат поверх неясного состояния, пока не сохранили нужную сцену. Если переключение
не завершилось, используйте предложенное повторение или восстановление. При успешном восстановлении
попросите агента вызвать `inspect_scene` и подтвердить модель, материал и режим.

Не редактируйте `chat.json`, `scene.3mf` или `index.json` во время работы STE. Для ручного восстановления
закройте слайсер и сначала сделайте копию всего каталога `brim/`. Последняя исправная сцена находится
в `chats/<id>/scene.3mf`; результаты последней нарезки — в `output/`.

## Ограничения обходных решений

Для нестабильной двухэкструдерной нарезки в текущем системном промпте рекомендован один экструдер.
Это не доказывает, что двухматериальная деталь выполнит исходное ТЗ. Аналогично переход с 5D на
classic нужно согласовать с требованиями детали. Открытые ошибки и границы проверки перечислены
в [ограничениях](limitations.md).
