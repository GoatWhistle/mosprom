# Ограничения

Состояние на 24 октября 2026 года, Brim 0.5.2. Код и локальные проверки не заменяют прогон
на поставке STE Slicer. [Результаты](evidence.md) показывают, что именно проверялось.

## Качество результата

- Семь моделей организаторов нарезаны и экспортированы. Физической печати, испытаний прочности,
  герметичности, износа, биения и допусков не проводилось.
- Эталонные 3MF есть только у организаторов. Близость к ним и итоговая оценка неизвестны.
- Свойства в справочнике относятся к семействам полимеров. Они не подтверждают свойства конкретной
  марки, наполнителя, партии или детали с выбранной ориентацией слоёв.
- Инженерные формулы — предварительные оценки. Например, расчёт Льюиса не учитывает все динамические
  нагрузки и анизотропию печатного зуба. Значение запаса нельзя выдавать за сертификацию.
- Анализ нависаний выполнен для фиксированного направления. Он не доказывает печатаемость в 5D.
  Геометрический анализ игнорирует самопересечения и детали меньше допуска сварки вершин.
- Распознавание дефектов на реальных фотографиях и улучшение после повторной печати не измерены.

## Ошибки слайсера и плагина

| Проблема | Статус и последствие | Обход / необходимая проверка |
|---|---|---|
| CuraEngine пропадает после некоторых 5D-прогонов (B17) | Открыта; следующая classic-нарезка может стоять на 0 % | Сохранить проект и перезапустить STE; автоматическое восстановление не реализовано |
| Два экструдера (B13) | Ошибка движка наблюдалась на стенде; путь не доказан стабильным | Текущий промпт рекомендует один экструдер, а запрос двух требует обсуждения |
| Новая сцена сохраняет материалы экструдеров (B15) | Открыта; overrides сбрасываются, материалы остаются | Перед нарезкой явно проверить и выбрать материал |
| Длинные варианты ответа (B6) | Могут обрезаться в панели | Использовать свободный текст; полный вариант сохраняется при выборе |
| Подтверждение вне видимой области (B14) | Иногда нужен ручной переход вниз | Кнопка «Новые сообщения» |
| Одинаковые названия чатов (B16) | Заголовок берётся из первого сообщения | Начинать сообщение с названия детали |
| Позднее открытие проводника после экспорта (B19) | Может перехватить фокус | Дождаться окна перед дальнейшими действиями |
| Неподтверждённые заявления LLM (B4, B18) | Наблюдались выдуманное вложение и заявление о проверке без вызова инструмента | Сверять ответ с лентой инструментов и реальной сценой |
| Старая браузерная вкладка после перезапуска | Порт и токен меняются | Открыть чат заново через меню STE |
| Версия MCP-сервера | `serverInfo.version` сообщает 0.4.0 при пакете 0.5.2 | Определять версию пакета по `plugin.json` |

Для крупных сеток промпт запрещает 5D при числе треугольников выше 200 000: в прошлых попытках
сетка 565 000 треугольников не завершала нарезку, а 73 000 нарезалась. Это эмпирическое правило
модели, а не доказанный предел движка или жёсткий валидатор инструмента.

## Калибровка и документы

Общая фигурка на профиле Fine 0,1 мм с brim оценивается в 3 ч 12 мин, 13,9 г
(один прогон STE 24.10.2026). Планируемый короткий тест за 30–60 минут не получился.
Журнал попыток проверен локально; его полный цикл с реальными фото на стенде не выполнен.

PDF поддерживается по текстовому слою; OCR, шифрование и произвольные варианты PDF не поддерживаются.
XLSX читается как сохранённые значения, без пересчёта формул; учитываются первые 64 столбца.
Визуальная структура документов при преобразовании в текст может упрощаться.

## Эксплуатация

- Нужна внешняя LLM с tool calling; без неё нет автономного сценария настройки.
- Прогоны семи моделей выполнены с Claude. Отдельные успешные запросы к LLM организаторов
  не подтверждают полный сценарий на ней. Зеркалирование не меняет модель, принимающую решения.
- Текущий backend всегда выбирает `opus`; выбор другого имени в клиенте это не меняет.
- Все сообщения и контекст отправляются провайдеру. При включённом зеркале их получает ещё один
  провайдер. Ключи в Preferences и файлы чатов не шифруются плагином.
- MCP-клиент с локальным токеном обходится без карточек подтверждения. Одновременная работа
  нескольких клиентов над сценой не является поддержанным пользовательским сценарием.
- `apply_changes` не транзакционный; отмена не откатывает уже выполненные операции.
- Лента панели держит все записи в памяти. Предел размера длительной переписки не измерен.
- Несохранённые черновики теряются при перезапуске; синхронизации чатов между машинами нет.
- Полный экспорт переписки с PNG доступен только из панели. Экспорт без успешной нарезки неполон.

## Что ещё не измерено

Нет измерения выигрыша по времени против ручной работы, стоимости полного сценария, точности
диагностики дефектов, частоты успеха на случайной выборке моделей или удобства для новичков.
Полная матрица инструментов на итоговой версии 0.5.2 и установка из финального комплекта на чистой
машине требуют отдельного прогона.
