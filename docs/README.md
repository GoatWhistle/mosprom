# Документация Brim

> Brim готовится к кейсу настройки FDM 3D/5D-печати в STE Slicer. Сейчас доступны бренд и серверный
> каркас; отдельный веб-фронтенд удалён, выбран встроенный чат STE Slicer; реализация плагина и сценарий проверки ещё не подтверждены. Документы ниже явно отделены от шаблонов.
