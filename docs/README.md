# Документация Brim

Brim 0.5.2 — плагин STE Slicer для подготовки FDM 3D/5D-печати через чат. Агент читает задачу,
документы и состояние сцены, уточняет требования, меняет настройки и получает G-code и 3MF.
Чат открывается в панели слайсера или системном браузере. История и проекты хранятся локально.
